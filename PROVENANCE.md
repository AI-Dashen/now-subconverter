# Provenance

GitHub identifies this repository as a fork of
[`zhongfly/now-subconverter`](https://github.com/zhongfly/now-subconverter),
whose fork network originates at
[`tindy2013/now-subconverter`](https://github.com/tindy2013/now-subconverter).

At the time this notice was added, the AI-Dashen branch had no pre-existing
commit unique to the fork when compared with its direct upstream branch; it
was behind upstream. Future differences must be determined from Git history,
not inferred from the repository owner or this notice.

When redistributing this fork:

- preserve the upstream Git history, copyright notices, and GPL-3.0 license;
- identify substantive modifications and their authors accurately;
- provide corresponding source as required by the GPL for distributed builds;
- do not describe the whole project as an original AI-Dashen work.
